# Navigo Design System

## Typography
- Custom premium font pairings (e.g. Inter, Outfit, system sans-serif).

## Colors
- Primary: Deep Carbon (`#09090b` / `#18181b`)
- Accents: Electric Blue, Transit Green, Tesla Red
- Transparency: Backdrop-blur and glassmorphism.

## Spacing & Radii
- Rounded corners (`rounded-2xl` / `rounded-3xl` for high-end floating overlays).
- Balanced padding margins.
