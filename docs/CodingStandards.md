# Navigo Coding Standards

## React Standards
- Functional components only.
- Strict TypeScript interface typings.
- Prefer RSC (Server Components) unless interactive state is needed.

## Styling Standards
- Vanilla CSS + Tailwind CSS utilities.
- Backdrop-blur overlays.
- Emissive glow maps in Three.js rather than CSS shadows.

## Three.js/R3F Standards
- Dynamic parameters defined in stores.
- Minimize direct re-renders using standard refs.
- Single responsibility modules.
